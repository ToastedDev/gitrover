---
title: auth
---

Authenticate GitHub for use with GitRover.

```bash
gr auth [subcommand]
```

- [`gr auth login`](#login) - Login to GitHub for use with GitRover.
- [`gr auth logout`](#logout) - Logout of GitHub for GitRover.

## login

Login to GitHub for use with GitRover.

```bash
gr auth login
```

## logout

Logout of GitHub for GitRover.

```bash
gr auth logout
```
