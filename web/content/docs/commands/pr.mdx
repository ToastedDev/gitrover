title: pr
---

Manage pull requests for a GitHub repository.

```bash
gr pr [subcommand]
```

- [`gr pr create`](#create) - Create a pull request on a GitHub repository.
- [`gr pr checkout`](#checkout) - Checkout a pull request from a GitHub repository.

## create

Create a pull request on a GitHub repository.

```bash
gr pr create
```

## checkout

Checkout a pull request from a GitHub repository.

```bash
gr pr checkout [pr-number]
```

- **pr-number**: The pull request number to checkout.
