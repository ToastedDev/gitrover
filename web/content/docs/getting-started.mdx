## Installation

GitRover publishes itself as a package on the [npm registry](https://npmjs.com). To install it, run the following command in your terminal:

## Logging in

To log into GitRover with your GitHub account, run the following command in your terminal:

```bash
gr auth login
```

This will ask you a few questions about how you want to login, and then it will open a browser window to authenticate with GitHub.
